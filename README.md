## Featured Systems

### [AgentGate](https://github.com/zihan001/agentgate)

**A policy firewall for AI agents.**

Open-source MCP proxy that intercepts tool calls before execution and applies deterministic policies to block dangerous parameters, unauthorized actions, and multi-step exfiltration chains.

Built around an async proxy, YAML policy engine, security detectors, and sequential tool-call analysis.

### [Gridstone Underwriter Copilot](https://github.com/zihan001/gridstone-underwriter-copilot)

**Underwriting triage with an audit trail.**

Turns unstructured property intake into ranked deals and audit-ready valuation memos. Valuation remains deterministic and reproducible, while the LLM is limited to the parts of the workflow where unstructured interpretation is actually useful.

Built as a finalist project for the KV Capital hackathon.
